# docs/showcase

Static GitHub Pages–ready showcase for CallScope (ADR-017).

- `index.html` — brand landing + sample call + links to eval/governance
- `VIDEO.md` — recording script for the interview demo video
- `assets/` — place `demo.mp4` after recording (see D-20260922-47)

Open locally: `open docs/showcase/index.html`
Or enable Pages on `main` → `/docs` (workflow: `.github/workflows/pages-showcase.yml`).
