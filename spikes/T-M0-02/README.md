# Spike T-M0-02 — Hermes call/turn ID correlation (S-1)

Throwaway probe: does request metadata reach Hermes plugin hook kwargs when
calling the OpenAI-compatible API server?

## Environment (recorded at run time)

See `ENVIRONMENT.md` (generated by `./run_probes.py`).

Pinned package: `hermes-agent==0.19.0` (PyPI; design mentioned 0.20.0 — not published
on PyPI at spike time; 0.19.0 is the latest available). Requires Python `>=3.11,<3.14`.

## Layout

| Path | Role |
|---|---|
| `plugin/` | Source for the kwargs-logging plugin |
| `mock_llm_server.py` | Tiny OpenAI-compatible stub (no GPU) |
| `run_probes.py` | Setup HERMES_HOME, start services, run matrix + cancel |
| `results/` | Scrubbed evidence (committed) |
| `.venv/` | Local install (gitignored) |
| `hermes_home/` | Isolated Hermes data dir (gitignored) |

## Rerun

```bash
cd spikes/T-M0-02
uv python install 3.12
uv venv --python 3.12 .venv
source .venv/bin/activate
uv pip install "hermes-agent==0.19.0" httpx
python run_probes.py
```

Do not import this into `callscope/` or `plugins/hermes_callscope/`.
